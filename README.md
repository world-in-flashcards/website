# website

The website of **World in Flashcards**: browse every card's content (names, maps, flags, emblems, recordings, and the
reasoning and sources behind each value), search the catalogue, and export any selection as an Anki deck.

It holds the static app (Svelte), the export and error-report functions (AWS Lambda) and the infrastructure (AWS CDK).

Status: not yet built.
